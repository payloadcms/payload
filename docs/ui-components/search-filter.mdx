The `SearchFilter` component renders a search input and reports changes after a 300 millisecond debounce. Use it when filtering a custom list or data view.

## Import

```tsx
import { SearchFilter } from '@payloadcms/ui'
```

## Interactive usage

<ComponentPreview component="SearchFilter" example="interactive" />

Use `label` to provide both the visible placeholder and the input's accessible name.

## Common props

| Prop               | Type                       | Default | Description                                    |
| ------------------ | -------------------------- | ------- | ---------------------------------------------- |
| `label`            | `string`                   | —       | Sets the placeholder and accessible label.     |
| `handleChange`     | `(search: string) => void` | —       | Receives the debounced search value.           |
| `searchQueryParam` | `string`                   | —       | Synchronizes the input with an external value. |

The legacy `fieldName`, `initialParams`, `setValue`, and `value` props are deprecated.
