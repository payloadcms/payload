Customize the look and feel of the Payload [Admin Panel](./overview) with your own stylesheets and design token overrides.

## Global CSS

Add global styles to the Admin Panel's `custom.css` file, which is loaded by its layout or route.

Here is an example of how you might target the Dashboard View and change the background color:

```css
.dashboard {
  background-color: red; // highlight-line
}
```

<Banner type="warning">
  **Note:** If you are building [Custom
  Components](../custom-components/overview), it is best to import your own
  stylesheets directly into your components, rather than using the global
  stylesheet. You can continue to use the [CSS library](#css-library) as needed.
</Banner>

### Specificity rules

Payload's default styles and design tokens are declared in `@layer payload-default`. Unlayered custom CSS takes precedence over these normal declarations, regardless of selector specificity or stylesheet load order.

For layered overrides, the Admin Panel declares a `payload` layer after `payload-default`.

Place custom rules in `@layer payload-default` when you want them to follow normal selector specificity and source order alongside Payload's defaults.

## Re-using Payload CSS variables

Payload defines its design tokens as [CSS Variables](https://developer.mozilla.org/en-US/docs/Web/CSS/Using_CSS_custom_properties) on both `:root` and `:host`. Custom admin components inherit these tokens without importing anything.

```css
@layer payload-default {
  .my-component {
    padding: var(--spacer-3);
    color: var(--color-text);
  }
}
```

### Dark Mode

Tokens default to light mode. Set `data-theme="dark"` or `data-theme="light"` on the document's `<html>` element or on the shadow host to select its palette. Add `data-enhanced-contrast` to that same element to enable enhanced contrast, including nested themed controls.

A nested `data-theme` changes colors and elevations while inheriting shared spacing, typography, radii, and component customizations.

<Banner type="warning">
  When overriding colors, check contrast in both themes and with enhanced
  contrast enabled.
</Banner>

### Overriding tokens

Override token values on `:root` in your own unlayered CSS:

```css
:root {
  --button-radius: 19px;
}
```

<Banner type="info">Inside Shadow DOM, override tokens on `:host`.</Banner>

### Using tokens outside the Admin Panel

Import `@payloadcms/ui/css/tokens` to use Payload's design tokens outside the Admin Panel without loading its resets, component styles, fonts, or global element styles:

```ts
import '@payloadcms/ui/css/tokens'
```

For Shadow DOM, load the stylesheet into the shadow root itself. A normal CSS import may place it in the outer document instead.

Values in `rem` use the document's root font size, including inside Shadow DOM. Load the fonts you want and apply typography tokens in your own styles.

## CSS Library

Payload uses [BEM naming conventions](http://getbem.com/) for Admin UI class names so you can target components and their states in your own stylesheets.

The main token definitions are available in these source files:

- [Color ramps](https://github.com/payloadcms/payload/blob/main/packages/ui/src/css/design-tokens.css): raw `--ramp-*` palette values.
- [Semantic colors](https://github.com/payloadcms/payload/blob/main/packages/ui/src/css/colors.css): theme-aware colors for backgrounds, text, borders, icons, and fields.
- [Spacing](https://github.com/payloadcms/payload/blob/main/packages/ui/src/css/spacing.css): spacers, gutters, field spacing, and breakpoint values.
- [Typography](https://github.com/payloadcms/payload/blob/main/packages/ui/src/css/typography.css): font families, sizes, weights, line heights, and letter spacing.
- [Radii](https://github.com/payloadcms/payload/blob/main/packages/ui/src/css/radius.css): border radii.
- [Elevations](https://github.com/payloadcms/payload/blob/main/packages/ui/src/css/elevations.css): shadows for canvases, tooltips, menus, and modals.
- [Component tokens](https://github.com/payloadcms/payload/blob/main/packages/ui/src/css/theme.css): dimensions, radii, and stroke widths for shared controls.
- [Z-index](https://github.com/payloadcms/payload/blob/main/packages/ui/src/css/z-index.css): stacking order for navigation, modals, popups, and portals.
- [Accessibility](https://github.com/payloadcms/payload/blob/main/packages/ui/src/css/accessibility.css): focus outline colors, widths, and offsets.

Admin-specific layout variables, such as navigation width and header heights, are defined separately in [app.css](https://github.com/payloadcms/payload/blob/main/packages/ui/src/css/app.css). They are not included in the token export.
