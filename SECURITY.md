# Security Policy

## Supported Versions

Payload actively supports the current major release with security updates.

| Version | Supported |
| --- | --- |
| 3.x | :white_check_mark: |
| < 3.0 | :x: |

## Reporting a Vulnerability

Please report any security issues or vulnerabilities privately to [security@payloadcms.com](mailto:security@payloadcms.com).

### Response Timeline
- We will acknowledge receipt of your security report within 48 hours.
- We will provide regular status updates regarding investigation and resolution.
